# Storefront homepage banner

NalakaPos owns the optional Ecommerce hero banner. Staff with `storefront.manage-homepage` can manage banners at `/settings/storefront-homepage`. The permission is granted to the business owner by migration `2026_11_02_000008_create_web_home_banners.php`. Other staff need an explicit permission assignment.

The settings page lists business-scoped banners with an image preview, Create/Edit dialog, and Activate/Deactivate actions. At most one banner is active per business through a business-row-locked activation transaction. The additive migration `2026_11_02_000009_allow_multiple_web_home_banners.php` removes the previous one-banner-per-business unique index. A banner has a headline, small heading, description, optional button and image. Button destinations are limited to `/shop` and `/cart`. Images are validated as JPEG, PNG or WebP up to 5 MB. Recommended dimensions are 1920 × 1080; input must be at least 800 × 450, at most 6000 × 4000 and at most 20 megapixels. Uploaded images are resized proportionally to fit within 1920 × 1080 and stored as WebP under Laravel's public `storefront-banners` disk path. The public API is `GET /api/storefront/v1/home-banner`; it returns only the active banner through a public field allowlist, or `{ "data": null }` when none is active, and sends `Cache-Control: private, no-store`.

Next.js reads the banner through its same-origin `/api/storefront/v1/home-banner` route. Locally hosted Laravel banner images bypass Next's remote-image optimizer, which otherwise can reject the local `127.0.0.1:8000` image URL with a 400 response. The homepage uses its built-in hero when the banner is absent or the API is unavailable. Product prices, promotion claims and order availability are not inferred from banner text. Staff must enter only approved commercial claims. No discount banner is generated from catalogue prices.

The multiple-banner migration was created as source only and was not run against the active POS database. Apply it through the reviewed deployment process before creating a second banner. Laravel's public storage link must be configured for uploaded images.
